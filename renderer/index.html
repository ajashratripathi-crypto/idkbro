How these estimates work

Local compute time is recorded by the app. Energy is estimated as device watts × response seconds ÷ 3,600; set the watts value in Settings. Water and climate comparisons require a baseline for cloud inference. Nexus Eco has no verified universal baseline, so you can enter your own and see it clearly identified as an assumption. Land use depends on data-center construction, electricity supply, and hardware production; this app does not claim a per-chat land saving.

About the fine-tune

NexusEco-3B is a Qwen-based fine-tune, not a model trained from scratch. The release should preserve the base model’s license and attribution. Review the bundled third-party notices before redistributing.

What makes this different?

Most online assistants send each prompt to remote servers. NexusEco downloads an open-weight model once, then runs it locally using llama.cpp. Local use avoids sending each chat request to an inference provider, but it still uses your device’s electricity and depends on the electricity mix and hardware.

Terms & privacy

Plain-language terms and privacy information for this local desktop app.

Privacy

NexusEco AI stores chat history and settings on this device. Chat prompts are sent to the local llama.cpp process at 127.0.0.1 only. The app does not send chat text to Nexus Eco AI servers. The model download is an internet request to the model host you choose. You can delete local chat history and model files at any time.

Use of the app

You may use the app for lawful personal, educational, and development purposes. Do not use generated output as a substitute for professional medical, legal, financial, or safety advice. Review generated code before running it.

AI output disclaimer

Responses are generated automatically and can be false, incomplete, biased, or outdated. Nexus Eco AI does not guarantee accuracy, availability, or fitness for a particular purpose. You are responsible for checking information and deciding how to use outputs.

Model and third-party software

NexusEco-3B is based on Qwen2.5-3B-Instruct and uses llama.cpp. Their licenses and notices are included with the project and must remain available when redistributing those components. Model weights may have additional terms; check the model repository before sharing the model file.

Cost

The app is free to use. Downloading the model requires an internet connection and data; running the model uses the computer’s resources.

Changes

If these terms change materially, the app should show the updated terms and ask for acceptance again.
